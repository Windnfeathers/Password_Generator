# Password Generator

A cryptographically secure password generator with an encrypted word list and three security levels. Built for IT administrators and end users who need strong, memorable passwords without relying on online tools.

## How It Works

Passwords are generated by combining words from an encrypted word list with random casing, symbol injection, and digit blocks. The security comes from the generation algorithm and cryptographic randomness -- not the secrecy of the word list itself.

All randomness is handled by Python's `secrets` module, which uses the operating system's cryptographically secure random number generator.

## Security Levels

**Low** -- Reduced capitalization, standard length (9-15 characters). Suitable for systems with basic password requirements.

**Standard** -- Balanced capitalization, symbol injection, and digit blocks. Targets 12-15 characters. Good for most use cases.

**High** -- Long multi-word passwords with aggressive symbol injection and higher entropy. No length cap. Recommended for high value accounts.

## Bulk Generation

Enter any number of passwords to generate. Up to 10 passwords display directly in the application window. More than 10 prompts you to save the results to a text file.

## Files

| File | Purpose |
|------|---------|
| `Password_Generator.py` | Main application |
| `encrypt_words.py` | Utility to generate your own encrypted word list |
| `words.csv` | Plain text source word list |
| `encrypted_words.csv` | Encrypted word list used by the generator |
| `key.key` | Encryption key required by the generator |

## Installation

A packaged Windows installer is available in Releases. Download and run -- no Python installation required.

To run from source, install dependencies and run `Password_Generator.py`. The `encrypted_words.csv` and `key.key` files must be in the same directory as the script.

## Requirements

- Windows OS
- Python 3.x (if running from source)
- cryptography: `pip install cryptography`

## Using Your Own Word List

To generate a custom encrypted word list:

1. Edit or replace `words.csv` with your own words, one per line
2. Run `python encrypt_words.py`
3. New `encrypted_words.csv` and `key.key` files will be generated
4. Use `python encrypt_words.py --new-key` to force a new encryption key
